# APPJIRAFA

Aplicación Android offline para la experiencia educativa interactiva de la **Jirafa** de IMAGINAR.

- Pantalla táctil horizontal 16:9.
- Resolución de diseño: 1920 × 1080.
- Compatible con el TV Box validado API 25 (Android 7.1).
- WebView local, sin Internet.
- Build oficial mediante Gradle/GitHub Actions.

El APK generado se llama `appjirafa.apk`.
